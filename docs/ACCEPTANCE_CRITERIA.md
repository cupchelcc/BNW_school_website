# เกณฑ์การตรวจรับงาน (Acceptance Criteria)

|---|---|---|---|
| **1. การรักษาข้อมูลเดิม** | โฟลเดอร์เดิม `C:\Users\cupch\Documents\bnw-school-website` ไม่ถูกแก้ไขหรือลบ | ตรวจสอบ Last Modified Date และ Git status | โฟลเดอร์เดิมคงสภาพเดิม 100% |
| **2. ความถูกต้องของสภาพแวดล้อม** | พัฒนาใน `D:\BNW Website` บน Node 24 และ TypeScript | ตรวจสอบตำแหน่งไฟล์และ configuration | ใช้งานได้สมบูรณ์ในไดรฟ์ D: |
| **3. เว็บไซต์สาธารณะ** | แสดงผลครบถ้วนทั้ง 18 หน้า มีระบบค้นหา กรองหมวดหมู่ และ Responsive | ทดสอบเปิดหน้าเว็บทุกหน้าบนขนาดจอ Desktop, Tablet, Mobile | หน้าเว็บแสดงผลถูกต้อง ไม่มี Broken Link |
| **4. ระบบสิทธิ์และความปลอดภัย** | รองรับ 4 บทบาท (Super Admin, Site Admin, Editor, Author) ป้องกัน Route ฝั่งเซิร์ฟเวอร์ | ทดสอบล็อกอินด้วยสิทธิ์ต่าง ๆ และยิง API ตรง | Author ไม่สามารถเผยแพร่เนื้อหาได้, Guest เข้าไม่ได้ |
| **5. ระบบ CMS** | สร้าง แก้ไข ลบ จัดการสถานะ Draft, Scheduled, Published ได้ | ทดสอบสร้างข่าว Draft แล้วตรวจสอบหน้าสาธารณะ | ข่าว Draft จะไม่ปรากฏต่อสาธารณะจนกว่าจะ Published |
| **6. Visual Page Builder** | เพิ่ม ลบ สลับลำดับบล็อกทั้ง 15 ประเภท บันทึกลงฐานข้อมูล และคงอยู่หลังรีโหลด | ทดสอบสร้างหน้าใหม่ จัดวางบล็อก บันทึก รีโหลดหน้าจอ | ข้อมูลบล็อกแสดงผลตรงกันทั้งใน Preview และหน้าจริง |
| **7. Theme Customizer** | ปรับแต่งค่าสี โลโก้ ข้อความหัวเว็บ ท้ายเว็บ โซเชียล และเมนูได้ | เปลี่ยนสีหลักหรือข้อความติดต่อ บันทึก แล้วดูหน้าแรก | เว็บไซต์สาธารณะเปลี่ยนค่าตามที่บันทึกไว้ในฐานข้อมูล |
| **8. Media Library** | อัปโหลดรูปภาพ จัดการ Alt Text ค้นหาไฟล์ และป้องกันการลบไฟล์ที่ใช้งานอยู่ | อัปโหลดภาพ เพิ่ม Alt Text แล้วดึงไปใช้ในบล็อก | บันทึก Metadata ครบถ้วน และแสดงผลถูกต้อง |
| **9. สวนพฤกษศาสตร์โรงเรียน** | ค้นหาพรรณไม้ตามชื่อไทย/ชื่อวิทยาศาสตร์ แสดงข้อมูลเพื่อการเรียนรู้ | ค้นหาพรรณไม้ เช่น "ราชพฤกษ์", "ทองกวาว" | แสดงข้อมูลทางพฤกษศาสตร์และภาพประกอบอย่างถูกต้อง |
| **10. การสำรองและกู้คืน** | มีสคริปต์ Backup และ Restore ฐานข้อมูลที่ทดสอบจริงแล้ว | รันคำสั่ง backup และ restore ลงฐานข้อมูลแยก | ข้อมูลถูกกู้คืนได้อย่างสมบูรณ์ ไม่สูญหาย |
| **11. การทดสอบและการ Build** | รัน Typecheck, Unit Tests และ Production Build ผ่าน 100% | รันคำสั่ง `pnpm build` และ `pnpm test` | Build สำเร็จโดยไม่มีข้อผิดพลาด (Exit Code 0) |
| **12. เอกสารส่งมอบ** | มีเอกสารครบถ้วนใน `docs/` ทั้ง 14 ไฟล์ตามข้อกำหนด | ตรวจสอบไฟล์ในโฟลเดอร์ `docs/` | ครบทุกไฟล์และมีเนื้อหาภาษาไทยที่ชัดเจน |
