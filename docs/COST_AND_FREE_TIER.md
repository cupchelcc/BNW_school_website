# การประเมินค่าใช้จ่ายและโควตาฟรี (Cost and Free Tier Analysis)
## โครงการ BNW-001 V2: โรงเรียนวัดบางน้ำวน (รอดพิทยาคม)

---

### 1. เป้าหมายด้านงบประมาณ
เป้าหมายของโครงการ BNW-001 V2 คือ **0 บาทต่อเดือน** สำหรับค่าบริการโครงสร้างพื้นฐานระบบ (Hosting, Database, Storage, CDN) โดยบริหารจัดการให้อยู่ภายในแผนบริการฟรี (Free Tier) อย่างปลอดภัย มั่นคง และมีประสิทธิภาพ

---

### 2. ตารางวิเคราะห์บริการและโควตาฟรี (Cloudflare-first Free Tier Breakdown)

| บริการ (Service) | ผู้ให้บริการ | โควตาฟรีต่อเดือน (Free Allowance) | ปริมาณการใช้งานที่คาดการณ์ของโรงเรียน | สถานะต้นทุน |
|---|---|---|---|---|
| **Cloudflare Pages / Workers** | Cloudflare | 100,000 requests/วัน (ประมาณ 3,000,000 req/เดือน) | ~5,000 - 20,000 req/วัน | **0 บาท** |
| **Cloudflare D1 (Database)** | Cloudflare | - อ่านข้อมูล (Reads): 5,000,000 rows/วัน<br/>- เขียนข้อมูล (Writes): 100,000 rows/วัน<br/>- ความจุฐานข้อมูล: 5 GB | - Reads: ~10,000 - 50,000 rows/วัน<br/>- Writes: ~100 - 500 rows/วัน<br/>- ขนาดข้อมูล: < 100 MB | **0 บาท** |
| **Cloudflare R2 (Object Storage)** | Cloudflare | - พื้นที่จัดเก็บ: 10 GB/เดือน<br/>- ปริมาณการดาวน์โหลด (Egress): **ฟรีไม่จำกัด**<br/>- การเขียน Class A: 1,000,000 req/เดือน<br/>- การอ่าน Class B: 10,000,000 req/เดือน | - พื้นที่จัดเก็บ: ~1 - 3 GB<br/>- Egress: สื่อโรงเรียนทั่วไป<br/>- Class A: < 1,000 req/เดือน | **0 บาท** |
| **Cloudflare DNS & SSL** | Cloudflare | ฟรีใบรับรอง Universal SSL/TLS ตลอดชีพ พร้อม DDoS Protection พื้นฐาน | 1 โดเมนโรงเรียน | **0 บาท** |
| **GitHub Actions (CI/CD)** | GitHub | 2,000 นาที/เดือน สำหรับ Public/Private Repo | ~100 นาที/เดือน | **0 บาท** |

### 3. ปัจจัยเสี่ยงที่อาจทำให้เกิดค่าใช้จ่าย และวิธีป้องกัน (Risk Mitigation)

1. **การอัปโหลดไฟล์วิดีโอหรือไฟล์ขนาดใหญ่เกินความจำเป็น:**
   - *ความเสี่ยง:* หากอัปโหลดไฟล์วิดีโอ MP4 ขนาดหลายร้อยเมกะไบต์ลงในระบบ จะทำให้พื้นที่ R2 เกิน 10 GB
   - *วิธีป้องกัน:* ในระบบ Media Library ได้จำกัดขนาดไฟล์อัปโหลดไว้ไม่เกิน 10 MB ต่อไฟล์ และแนะนำให้ครูฝังลิงก์วิดีโอจาก YouTube ทางการของโรงเรียนแทนการอัปโหลดไฟล์วิดีโอตรง
2. **การถูกยิง Request ปริมาณมหาศาล (Spam / Bot Crawlers):**
   - *ความเสี่ยง:* จำนวน Request หรือ D1 Query อาจพุ่งสูงเกินโควตาประจำวัน
   - *วิธีป้องกัน:* เปิดใช้งาน Cloudflare Bot Management พื้นฐาน, แคชหน้าเว็บส่วนใหญ่เป็น Static/ISR ผ่าน Cloudflare CDN เพื่อลดการเรียกฐานข้อมูล D1 ซ้ำซ้อน
3. **การลืมปิดหรือสร้างบริการที่เสียค่าใช้จ่ายโดยไม่ตั้งใจ:**
   - *วิธีป้องกัน:* ระบบปฏิบัติตามกฎห้ามผูกบัตรเครดิตสำหรับบริการเสริมที่เสียเงิน และห้ามสั่งคำสั่งอัปเกรดเป็น Paid Plan หากไม่ได้รับอนุมัติจากผู้บริหารสถานศึกษา

### 4. สิ่งที่ไม่ครอบคลุมในโควตาฟรี (Excluded Items)
- **ค่าธรรมเนียมจดทะเบียนโดเมนเนม:** ค่าบริการชื่อโดเมนโรงเรียน เช่น `.ac.th` (ของมูลนิธิ T.H.NIC) หรือ `.com` ต้องชำระตามรอบปีของนายทะเบียนโดเมนนั้น ๆ
- **บริการ SMS หรือ Third-party Line Notify เชิงพาณิชย์:** หากโรงเรียนต้องการส่งข้อความแจ้งเตือนทาง SMS จำเป็นต้องจัดหางบประมาณเพิ่มเติมตามการใช้งานจริง
