# คู่มือการใช้งาน Visual Page Builder (ระบบจัดหน้าเว็บด้วยบล็อก)
## โครงการ BNW-001 V2: โรงเรียนวัดบางน้ำวน (รอดพิทยาคม)

---

### 1. ทำความรู้จัก Visual Page Builder
**Visual Page Builder** ของระบบ BNW-001 V2 เป็นเครื่องมือจัดวางโครงสร้างหน้าเว็บที่ออกแบบมาให้ครูและบุคลากรสามารถจัดเรียงและปรับแต่งหน้าเว็บของโรงเรียนได้แบบเสมือนจริง โดยใช้ระบบ **บล็อกมาตรฐาน 15 รูปแบบ** ซึ่งมีความปลอดภัยสูง สวยงาม รองรับมือถือทุกขนาด และไม่ทำให้โครงสร้างเว็บเสียหาย

---

### 2. บล็อกมาตรฐานทั้ง 15 ประเภท (Standard Blocks Catalog)

| ลำดับ | ประเภทบล็อก | หน้าที่และลักษณะการใช้งาน |
|---|---|---|
| 1 | **Hero Banner** | ป้ายแบนเนอร์หลักขนาดใหญ่ด้านบนสุดของหน้าเว็บ พร้อมข้อความต้อนรับ ปุ่มกด และภาพพื้นหลัง |
| 2 | **Text Section** | ส่วนข้อความและย่อหน้า สำหรับพิมพ์วิสัยทัศน์ สารจากผู้อำนวยการ หรือเนื้อหาทั่วไป |
| 3 | **Image Single** | รูปภาพเดี่ยวขนาดใหญ่ พร้อมคำบรรยายใต้ภาพและการจัดวางกึ่งกลาง |
| 4 | **Image Gallery** | แกลเลอรีภาพถ่ายกิจกรรมแบบตารางหลายคอลัมน์ (2, 3 หรือ 4 คอลัมน์) |
| 5 | **News List** | ดึงรายการข่าวประชาสัมพันธ์ล่าสุดจากฐานข้อมูลมาแสดงอัตโนมัติ |
| 6 | **Announcement List** | ดึงรายการประกาศด่วนและประกาศโรงเรียนมาแสดง พร้อมป้ายสถานะปักหมุด |
| 7 | **Event List** | กล่องแสดงปฏิทินและกำหนดการกิจกรรมสำคัญ พร้อมวันที่และสถานที่ |
| 8 | **Staff Cards** | การ์ดแสดงรูปภาพและข้อมูลคณะผู้บริหารหรือคุณครูประจำกลุ่มสาระ |
| 9 | **Document List** | รายการแบบฟอร์มและเอกสารดาวน์โหลด พร้อมปุ่มดาวน์โหลดไฟล์ทันที |
| 10 | **Call to Action (CTA)** | กล่องข้อความกระตุ้นความสนใจ เช่น การเปิดรับสมัครนักเรียนใหม่ หรือปุ่มติดต่อโรงเรียน |
| 11 | **Image Slider** | สไลด์ภาพแบนเนอร์แบบเคลื่อนไหว สำหรับจัดแสดงภาพกิจกรรมเด่น |
| 12 | **Divider** | เส้นคั่นแบ่งส่วนเนื้อหา (แบบเส้นทึบ เส้นประ หรือเส้นจุด) เพื่อความเป็นระเบียบ |
| 13 | **Spacer** | ช่องว่างเว้นระยะแนวตั้ง เพื่อให้หน้าเว็บดูโปร่ง สบายตา และอ่านง่าย |
| 14 | **Botanical Highlights** | ดึงข้อมูลพรรณไม้เด่นจากสวนพฤกษศาสตร์โรงเรียนมาแสดง เพื่อส่งเสริมการเรียนรู้ |
| 15 | **E-Service Links** | การ์ดทางลัดเข้าสู่ระบบบริการออนไลน์ เช่น ระบบตรวจผลการเรียน SGS หรือห้องสมุด |

### 3. ส่วนประกอบของหน้าจอ Page Builder (3 Panels Layout)

หน้าจอแบ่งออกเป็น 3 ส่วนหลัก:

```
+----------------------------------------------------------------------------------+
| แถบควบคุมด้านบน: ชื่อหน้า | สลับโหมด (จัดบล็อก / ตัวอย่างจริง) | บันทึกแบบร่าง | เผยแพร่  |
+----------------------+------------------------------------+----------------------+
| แผงซ้าย (Left Panel)  | พื้นที่กลาง (Center Canvas)         | แผงขวา (Right Panel) |
| - รายการบล็อกในหน้า   | - แสดงผลหน้าเว็บแบบเรียลไทม์        | - ปรับแต่งคุณสมบัติ  |
| - ปุ่มเลื่อน ขึ้น/ลง  | - คลิกเลือกบล็อกเพื่อแก้ไข         |   (Title, Subtitle,  |
| - ปุ่มลบบล็อก         |                                    |    Images, Limits)   |
| - แผงเพิ่มบล็อกใหม่   |                                    |                      |
+----------------------+------------------------------------+----------------------+
```

### 4. ขั้นตอนการใช้งานทีละขั้นตอน (Step-by-Step Workflow)

#### 4.1 การเข้าสู่หน้าแก้ไข Page Builder
1. ที่เมนูผู้ดูแลด้านซ้าย เลือก **"Page Builder (จัดหน้าเว็บ)"**
2. คลิกปุ่ม **"เปิด Visual Builder"** ที่หน้าที่ต้องการแก้ไข (เช่น หน้าแรก `/home`)

#### 4.2 การเพิ่มบล็อกใหม่
1. ที่แผงด้านซ้ายล่าง บริเวณ **"เพิ่มบล็อกใหม่ (+15 บล็อก)"**
2. คลิกเลือกบล็อกที่ต้องการ เช่น `+ Hero Banner` หรือ `+ News List`
3. บล็อกใหม่จะถูกแทรกเข้าไปที่ด้านล่างสุดของหน้าเว็บทันที

#### 4.3 การสลับลำดับบล็อก
- ที่แผงด้านซ้าย ในรายการบล็อก:
  - คลิกปุ่ม **ลูกศรขึ้น (↑)** เพื่อขยับบล็อกขึ้นด้านบน
  - คลิกปุ่ม **ลูกศรลง (↓)** เพื่อขยับบล็อกลงด้านล่าง
  - คลิกปุ่ม **ถังขยะ (🗑️)** เมื่อต้องการลบบล็อกที่ไม่ใช้งาน

#### 4.4 การแก้ไขข้อความและรูปภาพในบล็อก
1. คลิกที่บล็อกที่ต้องการแก้ไขในรายการซ้าย หรือคลิกบนผืนผ้าใบกลาง
2. ที่ **แผงด้านขวา (Property Inspector)** จะปรากฏช่องกรอกข้อมูลเฉพาะของบล็อกนั้น เช่น หัวข้อ, คำบรรยาย, ปุ่มกด, หรือจำนวนข่าวที่ต้องการให้แสดง
3. เมื่อพิมพ์ข้อความหรือปรับค่า การแสดงผลบนผืนผ้าใบตรงกลางจะอัปเดตให้เห็นในทันที

#### 4.5 การดูตัวอย่างเสมือนจริง (Live Preview)
- คลิกที่ปุ่ม **"โหมดตัวอย่างจริง (Preview)"** บนแถบเครื่องมือด้านบน
- ระบบจะซ่อนเครื่องมือทั้งหมด และแสดงหน้าเว็บจริงตามที่นักเรียนและผู้ปกครองจะเห็น 100%

#### 4.6 การบันทึกและการเผยแพร่
- **"บันทึกแบบร่าง":** บันทึกการแก้ไขลงฐานข้อมูล แต่ยังคงสถานะ Draft ไว้สำหรับตรวจทาน
- **"เผยแพร่สู่หน้าเว็บ":** ข้อมูลบล็อกทั้งหมดจะถูกบันทึกลงฐานข้อมูลจริง และปรากฏบนเว็บไซต์โรงเรียนทันที
