### 2. วัตถุประสงค์และกลุ่มผู้ใช้งาน
1. **นักเรียน ผู้ปกครอง และประชาชนทั่วไป:**
   - เข้าถึงข้อมูลข่าวสาร ประกาศ กิจกรรม ปฏิทินการศึกษา ข้อมูลวิชาการ ทำเนียบบุคลากร
   - ใช้งานระบบบริการออนไลน์ (E-Service) และดาวน์โหลดเอกสารแบบฟอร์มต่าง ๆ
   - ศึกษาค้นคว้าฐานข้อมูลสวนพฤกษศาสตร์โรงเรียน
   - ใช้งานได้ราบรื่นทั้งบนสมาร์ตโฟน แท็บเล็ต และคอมพิวเตอร์
2. **ครูและบุคลากรทางการศึกษา:**
   - จัดการเนื้อหา ข่าวสาร กิจกรรม และเอกสารผ่านระบบ CMS ที่ใช้งานง่าย
   - ปรับแต่งหน้าเว็บด้วย Visual Page Builder (ระบบบล็อกมาตรฐาน 15 รูปแบบ) โดยไม่ต้องเขียนโค้ด
   - จัดการคลังสื่อ (Media Library) รูปภาพและเอกสารอย่างเป็นระเบียบ
3. **ผู้ดูแลระบบโรงเรียน (Administrators):**
   - ควบคุมสิทธิ์การเข้าถึงตามบทบาท (Super Admin, Site Admin, Editor, Author)
   - ปรับแต่งอัตลักษณ์ของเว็บไซต์ผ่าน Theme Customizer (สี โลโก้ เมนู ข้อมูลติดต่อ)
   - ตรวจสอบประวัติการทำงาน (Audit Logs) และสำรอง/กู้คืนข้อมูลได้อย่างปลอดภัย

---

### 3. อัตลักษณ์และการออกแบบ (Brand Identity & Design)
- **แนวคิดการออกแบบ:** Modern Academic, Professional, Friendly, Minimal, Accessible
- **โทนสีหลัก:**
  - น้ำเงินกรมท่า (Navy Blue: `#0b1f3c` / `#1e3a8a`): สื่อถึงความมั่นคง ทางการ ปลอดภัย และวิชาการ
  - สีเหลือง/ทอง (Gold/Yellow: `#eab308` / `#f59e0b`): สื่อถึงคุณธรรม ความสดใส และพลังแห่งการเรียนรู้
- **แบบอักษร (Typography):**
  - ฟอนต์หลัก: `IBM Plex Sans Thai` รองรับการอ่านภาษาไทยได้อย่างชัดเจน สวยงาม และเป็นทางการ
- **การเข้าถึง (Accessibility & Performance):**
  - รองรับการนำทางด้วยแป้นพิมพ์ (Keyboard Navigation), Focus Ring ชัดเจน, ฟอร์มมี Label ชัดเจน, Contrast Ratio ผ่านเกณฑ์ WCAG 2.1 AA
  - โครงสร้าง Semantic HTML และ Responsive Layout ครอบคลุมทุกขนาดหน้าจอ

---

### 4. ฟังก์ชันหลักของระบบ (Core Features)
1. **เว็บไซต์สาธารณะ 18 หน้าหลัก:** ครอบคลุมข้อมูลองค์กร บุคลากร ข่าวสาร กิจกรรม วิชาการ ผลงาน เอกสาร สวนพฤกษศาสตร์ และ E-Service
2. **ระบบยืนยันตัวตนและความปลอดภัย:** Login/Logout, Secure Cookie Session, Role-Based Access Control (RBAC), Password Hashing (scrypt/bcrypt), Audit Logs
3. **ระบบจัดการเนื้อหา (Custom School CMS):** รองรับสถานะ Draft, Scheduled, Published, Archived พร้อมระบบหมวดหมู่และการค้นหา
4. **Visual Page Builder:** สร้างและจัดลำดับบล็อกเนื้อหา 15 ประเภท พร้อมโหมด Live Preview และบันทึกลงฐานข้อมูลจริง
5. **Theme Customizer:** ปรับแต่งค่าสี โลโก้ แบนเนอร์ ข้อมูลติดต่อ Social Links และลำดับเมนู
6. **Media Library:** อัปโหลด ค้นหา กรอง จัดการ Metadata และ Alt Text ป้องกันการลบไฟล์ที่กำลังถูกใช้งาน
7. **โมดูลเฉพาะทางของโรงเรียน:** ข่าวสาร ประกาศ กิจกรรม ทำเนียบบุคลากร หลักสูตร/วิชาการ เอกสารดาวน์โหลด บริการออนไลน์ และฐานข้อมูลสวนพฤกษศาสตร์โรงเรียน
